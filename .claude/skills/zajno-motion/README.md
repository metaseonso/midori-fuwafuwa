# Zajno Motion Skill

A Claude Code / Claude Agent SDK skill that captures the 8 motion-design
principles published by **Zajno Digital Studio** at
[motion.zajno.com](https://motion.zajno.com), plus the technical recipe
(GSAP + Lenis + Lottie + ScrollTrigger) extracted from their production
source.

## Quick start

In Claude Code:

```
"Apply the zajno-motion skill — I need a hero reveal that feels premium"
```

Claude will read `SKILL.md`, pull the relevant principle(s), and use the
matching `examples/` snippet as a starting point.

## What this skill is NOT

- Not a 1:1 clone of motion.zajno.com (that would be a copyright issue).
- Not a no-code generator — you read the principle, write the code.
- Not a substitute for taste — the principles are *vocabulary*, not a recipe.

## Crediting Zajno

The 8 principles are Zajno Digital Studio's published intellectual work.
This skill is a structured re-presentation of public material with code
recipes derived from publicly-served front-end source. When you ship
something using these patterns, credit them if the framing is recognizable.

## Distributing to your team

See `INSTALL.md`. Short version:

```bash
cp -R ~/.claude/skills/zajno-motion /your/teammate/.claude/skills/
```

Or vendor it inside a project under `.claude/skills/zajno-motion/`.
