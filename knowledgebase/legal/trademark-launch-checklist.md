# ✅ Trademark launch checklist

Written so it can be picked up later without re-deriving anything. Hand it to an attorney or run
it yourself.

**Office of origin: USPTO** (founder is US-based, confirmed 2026-08-19).

---

## Now — free, today

- [ ] Add **™** after "Midori Fuwafuwa" wherever the name appears as a brand: site header and
      footer, book copyright pages, app store listings, social profiles, decks, merchandise mockups.
- [ ] Add the **©** footer notice — see [[../site/site-notices]].
- [ ] Do **not** use ® anywhere yet. See [[trademark-is-territorial]].

## Before first launch

- [ ] **Confirm the domain is available** and matches the mark you intend to register. Do this
      *before* filing — a mark you cannot get a domain for is a problem you want to find early.
- [ ] **Run a clearance search.** Check no one already holds a confusingly similar mark in your
      classes. Filing into a conflict wastes the fee and the months of waiting.
- [ ] **Decide what gets registered.** Likely three separate filings:
      - [ ] Studio name — "Midori Fuwafuwa"
      - [ ] The logo
      - [ ] Product/character names, if used to sell — "The Kits", "Whimsy"
- [ ] **Pick your classes** (fees are per class):
      - [ ] Class 16 — printed matter, books
      - [ ] Class 9 — software, apps
      - [ ] Class 41 — entertainment, publishing
      - [ ] Class 25 — clothing *(only if merch)*
      - [ ] Class 28 — toys, games *(only if merch)*
- [ ] **Choose a Chinese-character name** for the studio, deliberately. See
      [[china-first-to-file]] — if you don't pick one, the market picks for you.

## At first launch

- [ ] File the **USPTO application.** This becomes your Madrid basis.
- [ ] File **one Madrid application** designating the market tier from [[madrid-protocol]]:
      EU · UK · Japan · South Korea · China · Canada · Australia
- [ ] **Prioritise China** if merchandise or Chinese manufacturing is anywhere in the plan.
      ⚠️ [[china-first-to-file]] — this is the one that fails badly if postponed.

## After registrations issue

- [ ] Switch **™ → ®** *per country, as each registration issues.* Not globally, not early.
- [ ] **Calendar renewal dates.** A lapsed mark can be taken by someone else.
- [ ] Add designations as new markets become real — no refiling needed.

---

## What this checklist does not need

- Copyright registration is **not** on here. You already hold worldwide copyright — see
  [[copyright-is-already-global]]. US registration adds US enforcement power later; it is not a
  launch blocker.
- A DMCA Designated Agent is **not** needed while the site accepts no user submissions. See
  [[../site/collect-nothing]].
