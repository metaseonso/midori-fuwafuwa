# Site notices

The © and ™ that go on the site, and everywhere else applicable.

## The footer

```
© 2026 Midori Fuwafuwa Studio™. All rights reserved.
```

Not legally required — [[../legal/copyright-is-already-global|copyright is automatic]] — but it makes
an "I didn't know" defence harder for anyone who copies the work.

## Standing convention — apply everywhere applicable

**™ after "Midori Fuwafuwa" wherever the name appears as a brand:**
- Site header / wordmark
- Site footer
- Book copyright pages
- App store listings
- Social profiles
- Decks and pitch material
- Merchandise and mockups

**© notice** in the site footer, and on book copyright pages.

**Never ®** until a registration actually issues — and then only in the country where it issued. See
[[../legal/trademark-is-territorial]].

## Why ™ now, free, today

™ requires **no registration.** It asserts an unregistered claim, is understood internationally, and
costs nothing. There is no reason to wait, and using it from the start strengthens the record of
continuous brand use.

## What is deliberately absent

- **No cookie notice** — there are no cookies. See [[collect-nothing]].
- **No consent banner** — nothing is written to the visitor's device. See
  [[what-triggers-a-consent-banner]].
- **No DMCA agent notice** — the site accepts no user submissions.
